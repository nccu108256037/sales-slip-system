# 神隊友／好貨倉 銷貨單系統

這是一套純前端、無後端的熱感應紙銷貨單系統。

## 功能

- 神隊友／好貨倉訂單來源切換
- 自動產生銷貨單號
- 店家名稱手動輸入
- 聯絡電話手動輸入
- 店家地址手動輸入
- 品名手動輸入
- 數量手動輸入
- 單價手動輸入
- 金額自動計算
- 金額可再手動修改
- 訂單備註
- 總計自動計算
- 應收款可手動修改
- 58mm 熱感應紙列印
- 80mm 熱感應紙列印
- 手機與電腦版面支援

## 隱私與資料保存

本系統刻意不使用：

- localStorage
- sessionStorage
- IndexedDB
- Cookie
- Supabase
- 後端資料庫

所有輸入內容只存在目前開啟的網頁中。

重新整理、關閉頁面或關閉瀏覽器後，資料會全部消失。
